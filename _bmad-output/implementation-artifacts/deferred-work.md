- source_spec: `{project-root}/_bmad-output/implementation-artifacts/spec-1-2-player-ship-and-twin-stick-movement.md`
  summary: `PlayerInputSampler.sample()` — the keyboard `(right-left, down-up)` axis mapping and the gamepad-priority deadzone fall-through — has no automated coverage; consider driving `sample()` with a fake keys/pad object (or extracting the pure axis-resolution decision) to assert control mapping and pad↔keyboard priority.
